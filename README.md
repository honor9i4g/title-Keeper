# 🎖️ Title-Keeper

**Title-Keeper** is a Minecraft title and badge plugin project designed to make in-game titles more customizable and enjoyable. It provides built-in automatic titles, badge titles, custom title options, and colour customization features.

The project continues to improve with new features, expanded badge collections, compatibility updates, and bug fixes.

> 🚀 **Current Version: 1.6.0**

---

## ✨ Features

- 🎖️ **Built-in Automatic Titles** — Includes automatic title functionality without requiring additional ZIP files.
- 🏅 **Badge Titles** — Add badge-based titles to give players more ways to customize their in-game identity.
- 🎨 **Built-in Colour Selection** — Choose colours for titles using the built-in colour selection feature.
- 🌈 **Hex Colour Support** — Customize title colours using hexadecimal colour codes.
- ✏️ **Custom Titles** — Supports custom titles for a more personalized experience.
- 🏆 **100 Badges** — Version 1.5.0 expanded the badge collection to 100 badges.
- 🔧 **Bug Fixes** — Version 1.6.0 fixes a plugin recognition issue caused by a typo in `plugin.yml`.
- 📈 **Continuous Improvements** — The project can continue to grow with future updates and enhancements.

---

## 📥 Installation

Follow these general steps to install Title-Keeper:

1. Download the appropriate project release or files from the repository.
2. Check whether your selected version requires a ZIP file.
3. Follow the installation instructions provided for that version.
4. Place the plugin files in the appropriate location for your Minecraft server or supported environment.
5. Restart the server or reload the plugin as recommended by its documentation.
6. Test the title and badge features to make sure everything works correctly.

**Important:** Check the requirements for your specific version before installing. Versions 1.2.0 through 1.5.0 are marked as requiring ZIP files in the project notes.

## 📦 Version History

### 🔹 Version 1.0.0
- Introduced the project with built-in automatic titles.
- Provided the initial title functionality.
- ZIP file not required, according to the project notes.

### 🔹 Version 1.2.0
- Added the requirement for a ZIP file for badge titles.
- Expanded the project with badge-related functionality.

### 🔹 Version 1.3.0
- Added support for Minecraft 26.3, as specified in the project notes.
- Continued development of the title and badge system.

### 🔹 Version 1.4.0
- Expanded the collection to **20 badges**.
- Added built-in colour selection.
- Introduced support for custom titles.
- Improved title customization options.

### 🔹 Version 1.5.0
- Expanded the collection to **100 badges**.
- Added support for **hexadecimal (HEX) colours** in titles.
- Improved the available customization options.

### 🔹 Version 1.6.0
- Fixed a plugin recognition issue.
- Corrected a typo in `plugin.yml` that caused the plugin not to be recognized properly.
- Included a fix based on the issue identified with help from DoodleworldOfficial.
